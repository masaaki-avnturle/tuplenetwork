## 要旨

**検証済** **第I部:第七の問題。** 楕円曲線 E/Q の Hasse–Weil L 関数 L(E,s) = Π_p(局所因子)⁻¹ は、解析器の辞書では「算術的スペクトルゼータ」である:Euler 積の係数 a_p = p + 1 − #E(F_p) が入力(算術側)、関数等式 s ↔ 2−s の中心 s = 1 が臨界線の中心(第十一巻で臨界線が二つの極の垂直二等分線であったのと同じ位置)、そして BSD 予想は「**中心零点の位数 ord_{s=1}L(E,s) はゼロモードの数——Mordell–Weil 群 E(Q) の階数 r——に等しい**」と読める。解析器で読んだ:導手 11, 37, 389, 5077 の四本の曲線について、関数等式の符号 ε を数値で決定し(±1 との偏差 ≤ 10⁻²⁹)、L(1)、L′(1)、L″(1)、L‴(1) を計算した。位数の読みは 0, 1, 2, 3 で、既知の Mordell–Weil 階数と全て一致した(定理2)。さらに先頭係数を BSD の右辺——実周期 Ω × 高さ行列式(レギュレータ)× 玉河数・Ш・捩れの補正——と比べ、四本全てで比 1 を 10⁻⁴ 以内で得た(定理3)。11a1 では L(1)/Ω = 0.2 が厳密に 5/25 = c₁₁·|Ш|/|T|² を再現する。第八巻以来の対応がここで完結する:**ゼロモードの数 n₀ は中心零点の位数として、log det (ζ′(0)) は高さの行列式として、L の中心に現れる**。

**古典** **零を零と証明するもの。** ただし数値の零(|L(389a1,1)| < 10⁻⁴⁰)は零の証明ではない。389a1 で L(1) = 0 が定理であるのは、modular symbol により L(E,1)/Ω が分母の押さえられた有理数だから(Manin)であり、5077a1 で L′(1) = 0 が定理であるのは Gross–Zagier の公式が L′(1) を Heegner 点の高さに変え、その点が捩れだからである。いずれも解析ではなく算術が零を確定する。そして位数と階数の同値は、ord ≤ 1 では証明済(Gross–Zagier 1986 + Kolyvagin 1990)、**ord ≥ 2 では一つの曲線についても未解決**である——Ш の有限性さえ知られていない。解析器は位数を読めるが、読みと階数を結ぶ橋は算術の側にあり、まだ架かっていない。

**検証済** **古典** **第II部:総括。** 七つの問題が一つの読み出し表に乗った。最右極(次元・臨界性:NS)、原点の値(ゼロモード:#SAT、ベッチ数)、原点の傾き(log det:形)、関数等式の奇部(曲率・対称性:RH)、無限遠(ギャップ:YM)、そして本稿で加わる**臨界線の中心**(零点の位数:BSD)。各問題の隙間も一列に並ぶ:非線形項の一冪(NS)、Euler 積の正値性(RH)、相対化しない下界(P≠NP)、サイクルの構成(Hodge)、作用素の存在(YM)、位数と階数の橋(BSD)。七つのうち解けた一つ——ポアンカレ予想——だけは、スペクトル量(Perelman の λ = 作用素 −4Δ+R の最小固有値)を**読む**のではなく**流す**ことで解けた。固有値に力学を与え、特異点を手術で切る——解析(流れ)と構造(手術)の両輪である。残る六つの問題は、それぞれの「流れ」を待っている。

# 第I部 第七の問題:BSD 予想 【検証済/古典】

## 1. 解析器の辞書:L(E,s) はどのゼータか

E/Q を有理数体上の楕円曲線(極小 Weierstrass 模型 y² + a₁xy + a₃y = x³ + a₂x² + a₄x + a₆、導手 N)とする。素数 p ∤ N に対し a_p = p + 1 − #E(F_p) と置き、Hasse–Weil L 関数を Euler 積

L(E,s) = Π_{p∤N} (1 − a_p p⁻ˢ + p^{1−2s})⁻¹ · Π_{p|N} (1 − a_p p⁻ˢ)⁻¹ = Σ a_n n⁻ˢ

で定める。解析器の言葉に翻訳すると:

| 解析器の量(第八〜十四巻) | 幾何・組合せでの姿 | BSD(本稿)での姿 |
|---|---|---|
| 入力:固有値の列 / Euler 積 | Δ の固有値;素数 | a_p = p + 1 − #E(F_p)(点の勘定) |
| 関数等式と臨界線 | 円の Poisson 対称性;Re s = ½(第十一巻) | Λ(s) = εΛ(2−s);中心 s = 1 |
| ゼロモードの数 n₀ | 連結成分、b_p、#SAT | **ord_{s=1}L = rank E(Q)(これが予想)** |
| ζ′(0) = log det(形) | 行列式・スケール | **Reg = det⟨P_i,P_j⟩(先頭係数の中身)** |
| 関数等式の奇部 | 曲率(第九巻) | ε = ±1:位数の偶奇を先に決める |
| 位相不変量(χ) | ゼータの原点 | \|Ш\|・捩れ・玉河数(先頭係数の定数) |

**古典** **定理 1(存在の前半は完了している;Wiles 1995、Taylor–Wiles 1995、Breuil–Conrad–Diamond–Taylor 2001)。** 全ての E/Q は保型的である:L(E,s) は重さ 2・レベル N の新形式の L 関数に一致し、したがって全平面に正則に解析接続され、Λ(s) = (√N/2π)ˢ Γ(s) L(E,s) が Λ(s) = ε·Λ(2−s)(ε = ±1)を満たす。

ここには第十四巻との対照がある。ヤン・ミルズでは「読むべきスペクトルを持つ作用素」の存在自体が問題の前半であり、未解決である(第十四巻 系1)。BSD でも s = 1 は Euler 積の収束域(Re s > 3/2)の外にあり、そこに L が「存在する」ことは自明ではなかった——クレイの公式問題文も解析接続を前提として断っている。その存在の前半が、この問題では 1995–2001 年に閉じた。**解析器が入力を持つ問題**である。だから読める。

**検証済** 保型性の帰結として、Λ(s) = ∫₁^∞ (t^{s−1} + ε t^{1−s}) h(t) dt、h(t) = Σ a_n exp(−2πnt/√N) が成り立ち(h(1/t) = εt²h(t) を用いた標準の分割)、s = 1 でのテイラー展開から

- L(E,1) = (1+ε) f(1)、一般に L(E,1) = f(A) + ε f(1/A)、f(A) := Σ (a_n/n) e^{−2πnA/√N}
- ε = −1 のとき L′(E,1) = 2 Σ (a_n/n) E₁(2πn/√N)(E₁ は指数積分)
- 下位の導値が全て消えるとき L⁽ᵏ⁾(E,1) = (2/C) Σ a_n I_k(n/C)、I_k(x) = ∫₁^∞ (log t)ᵏ e^{−xt} dt、C = √N/2π

が従う。f(A) + εf(1/A) が A に依らないことから、ε 自体を数値で決定できる(付録C)。

## 2. 中心零点の位数の読み出し

**検証済** **定理 2(四曲線での位数の読み出し)。** 導手 11, 37, 389, 5077 の楕円曲線(Cremona ラベル、極小模型)について、a_p を F_p 上の点の勘定で計算し(n ≤ 2000)、ε と中心導値を評価した。結果:

| 曲線 | [a₁,a₂,a₃,a₄,a₆] | N | ε 実測(±1 との偏差) | L(1) | L′(1) | L″(1) | L‴(1) | 位数の読み | 既知の階数 |
|---|---|---|---|---|---|---|---|---|---|
| 11a1 | [0,−1,1,−10,−20] | 11 | +1 (8×10⁻³¹) | 0.253841860856 | — | — | — | **0** | 0 |
| 37a1 | [0,0,1,−1,0] | 37 | −1 (2×10⁻³⁰) | 0(符号による) | 0.305999773834 | — | — | **1** | 1 |
| 389a1 | [0,1,1,−2,0] | 389 | +1 (6×10⁻³¹) | 6.9×10⁻³² | 0(符号による) | 1.51863300058 | — | **2** | 2 |
| 5077a1 | [0,0,1,−7,6] | 5077 | −1 (1×10⁻²⁹) | 0(符号による) | 3.0×10⁻³¹ | 0(符号+L′=0) | 10.3910994007 | **3** | 3 |

位数の読みは四本全てで Mordell–Weil 階数と一致した。階数の側は独立に検証できる:37a1 の (0,0)、389a1 の (0,0), (−1,1)、5077a1 の (−2,3), (−1,3), (0,2) が曲線上にあることは整数演算で確認済(付録C;これらが生成系であることは Cremona の表による **古典**)。中心値は公表値(Cremona / LMFDB:L(11a1,1) = 0.2538418609、L′(37a1,1) = 0.3059997738、L″(389a1,1)/2 = 0.7593165003、L‴(5077a1,1)/6 = 1.7318499001)と全桁一致する。

ここで起きていること。第八巻でゼロモードの数は連結成分、第十二巻で #SAT、第十三巻でベッチ数だった。ここでは**有理点の自由度**である。そして初めて、ゼロモードの数が「ゼータの値」ではなく「ゼータの零の位数」として現れた——第十一巻で「零点の位置は Euler 積の側にある」と書いた、まさにその臨界線の中心に。

## 3. 先頭係数は高さの行列式である

BSD 予想の精密形(Birch–Swinnerton-Dyer 1965;Tate の定式化):

L⁽ʳ⁾(E,1)/r! = Ω · Reg · Π c_p · |Ш| / |T|²

ここで Ω は実周期(E(R) 上の不変微分の積分)、Reg = det⟨P_i,P_j⟩ は生成系の Néron–Tate 高さ対の行列式、c_p は玉河数、Ш は Tate–Shafarevich 群、T は捩れ部分群である。

**検証済** **定理 3(先頭係数の検証)。** Ω を実周期の数値積分で、Reg を正準高さ ĥ(P) = lim h(2ⁿP)/4ⁿ(n = 8)と高さ対 ⟨P,Q⟩ = (ĥ(P+Q) − ĥ(P) − ĥ(Q))/2 で計算した:

| 曲線 | Ω 実測 | Reg 実測 | L⁽ʳ⁾(1)/r! | 比 L/(Ω·Reg) | BSD の予測 c·\|Ш\|/\|T\|² |
|---|---|---|---|---|---|
| 11a1 | 1.26920930428 | 1(r = 0) | 0.2538418609 | **0.2000000000** | 5·1/5² = **1/5** |
| 37a1 | 5.98691729246 | 0.05111064929 | 0.3059997738 | 1.0000148 | 1 |
| 389a1 | 4.98042512171 | 0.1524564451 | 0.7593165003 | 1.0000245 | 1 |
| 5077a1 | 4.15168798308 | 0.4171420612 | 1.7318499001 | 1.0000036 | 1 |

11a1 の比は 1/5 に 10⁻¹⁰ で一致する——分子の玉河数 c₁₁ = 5 と分母の捩れ |Z/5Z|² = 25(と |Ш| = 1)。37a1〜5077a1 の比 1 からのずれ(≤ 2.5×10⁻⁵)は正準高さの打ち切り n = 8 の誤差 O(4⁻ⁿ) で説明され、文献値(Reg(389a1) = 0.1524601780、Reg(5077a1) = 0.4171435588)への収束方向と整合する。

ここで第八・九巻の対応が完結する。ζ′(0) = log det——「形は傾きに宿る」——の算術版が Reg = det⟨,⟩ である。**ゼロモードの数(階数)が零の位数に、ゼロモードの空間の計量(高さ)の行列式が先頭係数に宿る。** 幾何で位相と形が ζ(0) と ζ′(0) に分かれて宿ったのと同じ分かれ方で、算術では階数と高さが位数と先頭係数に分かれて宿る(と予想される)。

## 4. 零を零と証明するもの

**検証済** 表(定理2)の「0」には三種類ある。(i) **符号による零**:ε = −1 なら L(1) = (1+ε)f(1) = 0 は恒等的で、証明を要しない。(ii) **数値の零**:L(389a1,1) の実測 |f(1)| < 10⁻⁴⁰(作業精度 40 桁)。これは証明ではない——有限精度の計算は「位数 ≥ 2 に見える」ことしか言えず、10⁻¹⁰⁰ の非零を排除できない。(iii) **算術で確定する零**:それでも L(389a1,1) = 0 は定理である。

**古典** **定理 4(零の確定は算術による)。** (i) Manin の modular symbol により L(E,1)/Ω は分母の押さえられた有理数である。したがって数値で |L(1)/Ω| が分母の逆数より小さければ L(1) = 0 が**証明**される(389a1:|L/Ω| < 10⁻⁴⁰)。(ii) Gross–Zagier(1986)は ε = −1 のとき L′(E,1) を Heegner 点 y_K の高さで表す:L′(E/K,1) = c·ĥ(y_K)。5077a1 では Heegner 点が捩れであり、よって L′(1) = 0 が**証明**される。零を確定するのはどちらも解析(数値)ではなく算術(有理性、点の構成)である。

これは第十二巻の「数え上げはスペクトルの外」、第十三巻の「代数性はスペクトルの外」と同じ形の壁の、最も精密な現れである。解析器は L の値をいくらでも精しく読む。しかし「この値は厳密に零である」という一句は、固有値の列(ここでは a_n の列)を有限個読むことからは決して出ない。それを言うのは modular symbol の有理性であり、Heegner 点の構成である——**零を保存するのは非零因子による乗算だけであり、零を確定するのは算術だけである。**

## 6. 隙間の形

**未検証** 隙間は二つ、明確である。

(i) **位数 ≥ 2 の橋が一本もない。** ord_{s=1}L ≥ 2 の曲線について、rank ≥ 2 も、Ш の有限性も、一つの例でも証明されていない。389a1 は「rank = 2 は降下法で証明済・ord = 2 は数値で読めるが位数 ≥ 2 の証明は modular symbol の零(位数 ≥ 1 と偶奇)まで」という、両側から掘られて貫通していないトンネルである。Gross–Zagier に相当する「位数 2 の対象」(高次 Heegner サイクル、Beilinson–Bloch)は構成されているが、非退化性が証明できない——第十三巻の「サイクルの構成」と同じ型の隙間が、ここでは「構成したサイクルの非自明性」として現れる。

(ii) **Ш の有限性。** 先頭係数の公式は |Ш| を含むが、Ш が有限であることすら一般には未解決である(ord ≤ 1 では Kolyvagin が有限性も与える)。Ш は「見えないゼロモード」——局所的にはどこでも自明だが大域的に非自明な捩れ——であり、解析器のいかなる読み出しにも現れない。

**予想** **予想 1(解析器の限界の定式化)。** a_p の列(=解析器の入力)から多項式時間で計算可能な量で、ord_{s=1}L ≥ 2 を証明できるものは存在しない——数値評価は任意の有限精度で位数の**上界の反証**(この位数では非零、を確定)しかできず、下界の証明には modular symbol(位数 0→1)、Heegner 点(1→2 の偶奇)を超える算術的対象を要する。反証条件:a_n の有限列から L(1) = L′(1) = 0 を厳密に確定するアルゴリズムの構成。

# 第II部 総括:七つの問題と一つの解析器

## 7. 解けた一つ:ポアンカレ予想

七つのうち一つだけが解けている。その解け方は、本枠組みにとって示唆的である(第八巻補篇「ガウスからサーストン・ペレルマンへ」で検証済)。

**検証済** **古典** Perelman の λ 汎関数は作用素 −4Δ + R の最小固有値であり(補篇 定理3)、Ricci フローの下で単調非減少である。等質幾何では λ = R(スカラー曲率)に一致し、8 つのモデル幾何のうち正規化フローの不動点は Einstein な 3 つ(E³, S³, H³)だけである(補篇 定理4、厳密な有理数計算)。数値積分で:歪んだ S³ は丸い S³ に収束し(R: 5.2571 → 5.9032)、Nil・Sol・SL(2,R)~ は不動点に達さず崩壊する(補篇 定理5)。

つまり、**解けた唯一の問題では、スペクトル量が静的に読まれたのではなく、流された。** λ に力学(Ricci フロー)があり、単調量として特異点形成を制御し、崩壊する部分は手術で切られた。解析(流れと単調性)と構造(手術・崩壊理論・8 幾何の分類)の両輪である。第十〜十五巻で見た各問題の隙間は、いずれも「読み」から「橋」への一歩が欠けている状態だった。ポアンカレ予想はその橋が実際に架かった唯一の例であり、橋は「固有値の流れ」だった。

**予想** **予想 2(各問題の「流れ」)。** 残る六問題にも、対応する変形理論が橋の候補として存在する:BSD には岩澤理論(Z_p 拡大に沿った Selmer 群の変形;Skinner–Urban)、RH には Euler 積の正値性(Weil の明示公式の正値性、Li の判定法)、YM には繰り込み群の流れ(Balaban の紫外安定性)、NS には部分正則性(CKN)からの拡張。いずれも「読み出しに力学を与える」型である。P≠NP と Hodge には流れの候補すら明確でない(GCT と Hodge 軌跡がそれぞれ最も近い)。本稿はこの対応の内容を何も証明していない。

### 14. 結語

十四巻と一つの補篇を通じて、解析器は同じ動作を繰り返してきた——固有値の列を受け取り、極とゼロモードと行列式を読む。本稿でその列は素数ごとの点の勘定になり、読み出しは臨界線の中心に置かれた零の位数になった。四本の曲線で、位数は有理点の自由度を正しく数えた。先頭係数は高さの行列式を正しく運んだ。読みは、どこまでも合っている。

そして、どこまで合っても証明にならない。位数 2 の零を零と言い切るために、Manin は有理数を、Gross と Zagier は虚二次体の点を持ち込んだ——列の外から。ポアンカレ予想を閉じるために、Perelman は固有値を読むのをやめて流した——列に力学を与えて。七つの問題の中で解析器が果たせる役割は、この二つの動作のあいだのどこかに、正確に測量された形で置かれている。

十四巻を貫く原理に、本稿は最後の一行を加える。

> 零を保存するのは非零因子による乗算だけであり、曲率はその乗算を級数に開き、重複度がその級数の項を数え、位相はゼータの原点に、形はその傾きに、臨界性はその最右極に宿り、臨界線はその二つの極の中間に引かれ、零点の位置は Euler 積の側にあり、零モードの数は幾何では読めて論理式では問題そのものであり、ゼロモードの空間の中でどの方向が代数的かは複素構造が決め、ゼロモードの次の固有値は無限遠に宿り、それを読むにはまず列がなければならず——そして臨界線の中心に置かれた零の位数は有理点の自由度を数えると予想され、位数は読めても、零を零と証明するのは、いつも算術の側である。

**本稿が肯定すること。** 定理2・3(数値検証を掲載;アルゴリズムは全て Cremona 1997 の教科書のもの)と、定理1・4・§5・§7 の古典の引用。本稿の寄与は、(i) 解析器の辞書に BSD を載せ、位数と先頭係数の読み出しを階数 0〜3 の四曲線で実測したこと、(ii) 「数値の零は零を証明しない」を壁 (f) として明示したこと、(iii) 七つの問題の到達点と隙間を一つの表に総括したこと、に限られる。新しい数学は主張しない。

**本稿が肯定しないこと。** BSD 予想の証明(いずれの方向にも)。他の五つの未解決問題の証明。ポアンカレ予想への新しい寄与(Perelman の結果の数値的確認のみ)。四曲線の数値からの一般の場合への外挿。生成系の独立な導出(Cremona の表を引用した;曲線上にあることのみ検証した)。ε の数値決定が符号の証明であるという主張(厳密には Atkin–Lehner 固有値による)。予想2(各問題の「流れ」)の内容。

**数値上の限界。** 正準高さは n = 8 の倍加打ち切りで相対誤差 ~10⁻⁵(定理3の比のずれはこれで説明されるが、独立な誤差評価は行っていない)。389a1 の L(1) の上界 10⁻⁴⁰ は作業精度 40 桁での値であり、それ以上は見ていない。導値の式は下位導値の消滅を仮定して適用した(消滅自体は ε の偶奇と数値による;循環はないが、位数の「読み」が仮定に依存する構造は明記しておく)。a_p の勘定は p ≤ 2000 の総当たりで、大きい導手には使えない。いずれも隠さず掲載した。
